문항 ID: iam-001
서비스: AWS IAM
질문: IAM은 무엇이고 왜 사용하는가?
답변: IAM은 AWS 리소스에 누가 어떤 작업을 수행할 수 있는지 제어하는 서비스다. 정책으로 허용 작업과 대상 리소스를 정하고, 역할을 통해 서비스나 사용자에게 필요한 권한을 부여할 수 있다.
출처 제목: What is IAM?
출처 URL: https://docs.aws.amazon.com/IAM/latest/UserGuide/introduction.html

문항 ID: iam-002
서비스: AWS IAM
질문: Lambda에 S3 전체 접근 권한을 미리 주어야 하는가?
답변: 실제 수행 작업에 필요한 권한만 부여한다. 현재 CloudMate의 상태 확인 함수는 S3를 읽지 않으므로 S3 권한이 필요하지 않다. 나중에 문서 접근이 필요해지면 대상 버킷과 접두사에 맞춰 권한을 검토한다.
출처 제목: Security best practices in IAM
출처 URL: https://docs.aws.amazon.com/IAM/latest/UserGuide/best-practices.html

문항 ID: ec2-001
서비스: Amazon EC2
질문: EC2는 어떤 서비스인가?
답변: EC2는 AWS에서 가상 서버를 실행하는 서비스다. 사용자는 운영체제와 인스턴스 유형을 선택하고 네트워크 및 보안 설정을 구성한다. CloudMate의 이번 주 상태 API는 Lambda를 사용하므로 EC2 인스턴스를 만들지 않는다.
출처 제목: What is Amazon EC2?
출처 URL: https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/concepts.html

문항 ID: s3-001
서비스: Amazon S3
질문: S3에서 버킷과 객체는 무엇인가?
답변: S3는 파일과 같은 데이터를 객체로 저장하는 서비스다. 버킷은 객체를 담는 저장 공간이고 객체 키는 버킷 안에서 데이터를 식별하는 이름이다. documents/aws-faq.txt에서 documents/는 객체 키의 접두사이며 일반 파일시스템의 실제 폴더와 다르다.
출처 제목: What is Amazon S3?
출처 URL: https://docs.aws.amazon.com/AmazonS3/latest/userguide/Welcome.html

문항 ID: s3-002
서비스: Amazon S3
질문: RAG 원본 문서를 공개 버킷에 올려야 하는가?
답변: 원본 문서를 공개할 필요는 없다. 퍼블릭 액세스를 차단하고 승인된 역할에만 필요한 접근을 허용한다. 이후 Knowledge Bases 연동 시에도 별도 역할과 데이터 소스 권한을 검토한다.
출처 제목: Blocking public access to your Amazon S3 storage
출처 URL: https://docs.aws.amazon.com/AmazonS3/latest/userguide/access-control-block-public-access.html

문항 ID: lambda-001
서비스: AWS Lambda
질문: Lambda는 어떤 방식으로 코드를 실행하는가?
답변: Lambda는 요청이나 이벤트에 응답해 함수를 실행하는 서비스다. 개발자는 함수 코드와 실행 설정을 배포한다. CloudMate에서는 API Gateway가 GET /health 요청을 Lambda로 전달하고 함수가 상태 JSON을 반환한다.
출처 제목: What is AWS Lambda?
출처 URL: https://docs.aws.amazon.com/lambda/latest/dg/welcome.html

문항 ID: lambda-002
서비스: AWS Lambda
질문: Lambda 실행 역할과 로그는 왜 필요한가?
답변: 실행 역할은 함수가 AWS 서비스에 접근할 수 있는 범위를 정한다. 이번 주 함수는 지정된 CloudWatch Logs 그룹에 실행 결과만 기록한다. 요청 본문이나 인증 토큰은 기록하지 않는다.
출처 제목: Defining Lambda function permissions with an execution role
출처 URL: https://docs.aws.amazon.com/lambda/latest/dg/lambda-intro-execution-role.html
