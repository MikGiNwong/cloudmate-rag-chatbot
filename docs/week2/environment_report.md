# 환경 구성 보고서 안내

텀프로젝트의 현재 환경 구성 보고서는 [CloudMate 환경 구성 보고서](../environment_report.md)로 정리했습니다.

AWS 리소스는 주차와 무관한 이름으로 관리하며, 현재 실행 증거는 [docs/evidence](../evidence/README.md), 제출 화면 촬영 방법은 [제출 안내](../submission_guide.md)를 확인하면 됩니다.

이 폴더의 evidence 파일은 최초 환경 구축 당시의 기록입니다. 기존 스택 이름과 응답 형식이 포함될 수 있으므로 현재 환경의 증거와 구분합니다. 최초 보고서 원문은 Git 이력에 보존되어 있습니다.
